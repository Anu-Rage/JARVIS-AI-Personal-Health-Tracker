# ADR-011: Photo Logging Sequenced to Phase 2.5, Not MVP or Phase 5

**Decision:** build text logging first, prove the pipeline, then add photo input to the *same* nutrition engine shortly after.

**Reasons:** avoids debugging two unproven input pipelines simultaneously; contains AI iteration cost to the cheaper text path first.

**Trade-offs:** a genuinely differentiating feature ships slightly later than day one.

**Revisit:** not needed — this is a sequencing decision, not a scope cut.
