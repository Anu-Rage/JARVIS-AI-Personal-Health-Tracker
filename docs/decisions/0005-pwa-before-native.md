# ADR-005: PWA before Native iOS

**Decision:** PWA for MVP.

**Alternatives:** SwiftUI native app immediately.

**Reasons:** no App Store friction, single codebase, fast iteration; HealthKit isn't needed until Phase 6 anyway.

**Trade-offs:** no deep HealthKit integration until native is built.

**Revisit:** Phase 6, once Apple Health data is a proven value-add.
